# VoxelCraft

3D воксельная песочница в браузере, аналог Minecraft. Написана на чистом
JavaScript + Three.js, без серверной части — играть можно прямо со
статической страницы.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статическая сборка в dist/
npm run preview  # запустить собранную версию
```

## Возможности

- **Процедурно генерируемый мир** на основе шумов (Simplex noise): рельеф,
  биомы (равнины / пустыня / горы / снежные пики), пещеры, рудные жилы,
  деревья. Размер мира — 8×8 чанков по 16×64×16 блоков.
- **Свободная игра**: ставить и ломать блоки лучом из камеры, исследовать
  мир, перестраивать его. Около 20 типов блоков (трава, камень, дерево,
  доски, стекло, песок, вода, ископаемые, снег, кирпич и т. д.).
- **Три режима** игры:
  - **Творчество** — бесконечные блоки, полёт по двойному пробелу или `F`,
    мгновенное разрушение, нет урона.
  - **Выживание** — HP/голод, ночные мобы (зомби), падение, утопление,
    добыча ресурсов, хардкор-выкапывание (зависит от прочности блока).
  - **Образование** — пошаговые подсказки (6 уроков), бесконечные блоки,
    встроенный туториал по управлению и редстоуну.
- **Редстоун-аналог**: рычаги, кнопки, провода, лампы. Сигнал
  распространяется по сети проводов с затуханием 0..15, кнопки дают импульс
  на ~1 секунду, лампы загораются от соседнего источника. Можно собирать
  простые логические цепи и переключатели.
- **Цикл день/ночь**: 10-минутный цикл, динамическое освещение и цвет неба.
- **Сохранение / загрузка** в `localStorage`: сохраняется зерно мира и
  только дельты изменений (быстро и компактно).

## Управление

| Действие | Клавиши |
|---|---|
| Движение | `WASD` |
| Прыжок / всплыть / в полёте — вверх | `Space` |
| Присесть / в полёте — вниз | `Shift` |
| Спринт | `Ctrl` |
| Сломать блок | ЛКМ (удерживать в выживании) |
| Поставить блок / нажать рычаг или кнопку | ПКМ |
| Взаимодействовать (рычаг/кнопка) | `R` |
| Слот хотбара | `1`–`9` или колесо мыши |
| Инвентарь / палитра блоков | `E` |
| Меню паузы | `Esc` |
| Переключить полёт (творчество/обучение) | `F` или двойной пробел |

## Архитектура

- `src/engine/blocks.js` — описания типов блоков.
- `src/engine/textures.js` — процедурный атлас 16×16 тайлов.
- `src/engine/world.js` — мир, чанки, генерация (шумы), биомы, деревья.
- `src/engine/mesher.js` — построение `BufferGeometry` для чанков с
  отбрасыванием невидимых граней и AO-подобным затемнением по сторонам.
- `src/engine/raycast.js` — DDA-рейкаст по воксельной сетке (для
  целеуказания при ломании/постановке).
- `src/engine/physics.js` — AABB-коллизии игрока с миром.
- `src/engine/player.js` — контроллер от первого лица, гравитация, плавание,
  полёт.
- `src/engine/redstone.js` — симуляция логики (BFS по проводам).
- `src/game/inventory.js` — инвентарь и хотбар.
- `src/game/mobs.js` — простые мобы (зомби с поведением "блуждание/погоня").
- `src/game/save.js` — сохранение/загрузка в `localStorage`.
- `src/game/education.js` — состояния туториала образовательного режима.
- `src/game/game.js` — основной игровой цикл, склейка всего вместе.
- `src/ui/` — HUD, меню, стили.
